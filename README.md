# Static Paint Studio

HTML / CSS / Vanilla JavaScript だけで動く、GitHub Pages 向けのペイントアプリです。
ビルドツールや外部ライブラリは不要です。`index.html` をブラウザで開けば動きます。

## 機能

- キャンバス幅・高さの変更
- 画像を新規編集として読み込み
- ペン、透過ペン、モザイクペン
- デフォルトパレット、カスタム色、アルファ値
- EyeDropper API による全画面スポイト、非対応ブラウザ向けのキャンバススポイト
- 同一色判定 range 付き塗りつぶし
  - クリック位置からの連結領域
  - 全キャンバスの同系色
- 貼り付け画像の追加、ドラッグ移動、四隅ハンドルでリサイズ
- 選択機能 ON/OFF
- 明るさ、コントラスト、彩度、アンビアンス、ハイライト、シャドウ、色温度、ストラクチャ、シャープのフィルター
- Undo / Redo / 手動セーブポイント
- PNG / SVG 出力

## GitHub Pages での公開

1. このフォルダの `index.html`, `styles.css`, `app.js` をリポジトリに置く。
2. GitHub の Settings → Pages で公開ブランチを選ぶ。
3. 公開 URL にアクセスする。

## 注意

- 全画面スポイトはブラウザの `EyeDropper API` に依存します。非対応ブラウザではキャンバス内スポイトを使ってください。
- フィルター保存時、貼り付け画像はキャンバスに統合されます。
- SVG 出力はラスター画像を SVG 内に埋め込む方式です。手描き線をベクターパス化するものではありません。
